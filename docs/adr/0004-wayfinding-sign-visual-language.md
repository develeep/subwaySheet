# 화면 시각 언어를 역 안내판 스타일로 바꾼다

화면이 흰 카드 여러 장을 같은 모양으로 쌓은 구성이라 무엇이 입력이고 무엇이 결과인지 위계가 약했다. 이 앱은 승강장에 서서 한 손으로 보는 도구라서, 사용자가 이미 읽는 법을 아는 지하철 안내판의 문법을 빌려 위계를 만든다.

- **어두운 안내판 면(`--color-sign`)과 노선 색 띠(`--band-height`)** 를 머리띠, 방면 표시, 추천 칸 판에만 쓴다. 이 셋이 화면에서 가장 먼저 읽혀야 하는 것이다.
- **구간 판은 노선도 모양**이다. 노선 색 선에 출발·도착 역이 매달리고, 역 줄과 방면 줄은 1px 구획선으로 나눈다. 면을 나누는 데 그림자와 그라디언트는 여전히 쓰지 않는다.
- **추천 칸 번호의 숫자만 `--text-display`(80~112px)** 로 키운다. "번째 칸"은 headline 크기로 붙인다.
- **버튼·칩은 완전히 둥근 알약(999px) 대신 각진 둥근 사각형(12px)** 으로 통일한다. 안내판의 판 모양과 맞춘다.
- **글꼴은 Pretendard**로 바꾼다. 한글 굵기 단계(800까지)가 넉넉해서 역 이름·칸 번호를 무겁게 쓸 수 있다.

다크 모드에서는 안내판 면(#222A35)이 카드 면과 가까워서, 시트의 선택된 선택지와 열차 그림의 "여기 타세요" 핀은 안내판 색 대신 반전 색(`--color-text`)을 유지한다. 방면 안내판 옆 보조 버튼("반대 방향으로")은 면 대신 테두리로 구분한다.

## Considered Options

- 지금 색·글꼴을 그대로 두고 카드 구성만 정리: 위험은 가장 작지만 화면 인상이 거의 바뀌지 않는다.
- 다크 우선(승강장 야간, 앰버 LED 숫자): 낮에 밖에서 보는 경우가 많아 라이트 모드를 보조로 두기 어렵다.
