# 승하차 인원은 연 1회 갱신되는 날짜별 시간대 데이터(OA-12921)로 만든다

PRD는 서울시 CardSubwayTime(OA-12252, 월 1회)을 주 데이터로 잡았지만, 이 데이터는 한 달의 평일과 주말을 합친 값이라 평일 추천에도 주말 인원이 섞인다. 그래서 서울교통공사 역별 일별 시간대별 승하차 인원(OA-12921, 날짜 × 1시간 × 역)으로 요일유형(평일 / 토요일 / 일요일·공휴일)별 시간대 분포를 만든다. 이 데이터는 연 1회만 갱신되어 최대 1년 가까이 묵지만, 역별 시간대 패턴은 해마다 크게 바뀌지 않고 요일이 섞이는 오차가 더 크다고 판단했다.

## Consequences

- 요일유형을 나눌 수 있게 되어 주말·공휴일 추천을 1단계부터 지원한다(PRD는 2단계로 미뤘었다). 혼잡도·환승인원도 평일/토/일 구분이 있다. 공휴일은 일요일 값으로 본다(혼잡도의 공휴일 처리는 미확인).
- 화면에는 "기준 월" 대신 "기준 기간"을 적는다.
- 월별 일별 데이터(OA-12914)로 최근 인원 규모를 보정하는 일은 3단계 보정 때 검토한다.

## Considered Options

- CardSubwayTime 그대로: 최신이지만 요일이 섞인다.
