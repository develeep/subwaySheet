# 서울 지하철 역별 OD 데이터 조사 (2026-10-19, #24)

질문: data.go.kr 15113638 "서울특별시_지하철 역별 OD"를 월별 배치에 쓸 수 있나?

## 결론

**전체 데이터는 아직 받지 못했다.** 공개된 것은 2023-12-31(일요일) 하루치 샘플뿐이고, 파일 다운로드와 Open API 모두 이 샘플만 준다. 전체는 기간을 적어 이메일로 요청해야 한다. 샘플 기준으로 **시간대·방향 컬럼이 없고, 갱신 주기는 "수시(1회성)"** 라 월별 자동 갱신 원본으로는 쓸 수 없다. 쓴다면 받은 파일을 손으로 넣는 일회성 보정 자료다.

## 확인 못 한 것

- 전체판의 실제 기간(페이지는 기간 미기재, API 설명은 "2022년 10개월 치"), 컬럼이 샘플과 같은지.
- 전체판에 시간대가 있는지(샘플에는 없음).
- 정제 결과를 공개 저장소에 커밋·배포하는 것: 공공누리 1유형이면 출처표시로 가능하다고 보지만, 이메일로 받은 전체판에 별도 조건이 붙는지는 받아 봐야 안다.
- 이메일 요청 창구: 페이지에 제공부서 전화·메일이 비어 있다. 문의는 제공기관 관리부서로 하라고만 되어 있고, 포털 상담은 opendata_help@nia.or.kr, 1566-0025.

## 월별 배치에 넣는 방식

- **자동 다운로드: 불가.** 파일·API 모두 샘플 하루치만 준다. 갱신도 "수시(1회성)"다.
- **수동 갱신만 가능.** 받은 파일을 `raw/`에 넣고 배치가 읽게 한다. 갱신 시점이 없으니 월별 cron의 입력이 아니라 고정 보정값으로 다루는 편이 맞다.
- **시크릿: 필요 없음.** 샘플은 로그인 없이 받고, 전체판은 이메일 파일이다. API는 활용신청 뒤 `DATA_GO_KR_KEY`로 되지만 샘플과 같은 내용이라 쓸 이유가 없다.
- 하루 합계뿐이라 시간대·방향은 기존 승하차(OA-12252)·혼잡도(OA-12928)와 섞어 써야 한다(`ridership-day-types.md`).
